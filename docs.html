Multi-OS Virtual Machine Documentation

PC-Free allows running Linux, Android, Windows, macOS, and iOS directly in your browser using Docker and KVM acceleration without any local installation.

Supported Operating Systems

Windows

Port 8006 (noVNC / RDP)

Linux

Port 8007 (Ubuntu Desktop)

Android

Port 8008 (Redroid / Scrcpy)

macOS

Port 8009 (KVM macOS)

iOS

Port 8010 (Touch Simulator)

Zero-Lag Performance Optimization

  • Enable KVM Passthrough: Verify ls -la /dev/kvm exists in GitHub Codespaces for full virtual CPU hardware speed.
  • Adjust Shared Memory: Ensure shm_size: 2gb is set in Docker compose for browser video streaming.
  • Codespace Sizing: Select a 4-core or 8-core Codespace instance for optimum web frame rates.

Unified Command Execution

Run all operating systems simultaneously or individually:

# Launch all Virtual Machines
docker-compose up -d

# Launch specific OS
docker-compose -f linux.yml up -d
docker-compose -f android.yml up -d
docker-compose -f windows.yml up -d
docker-compose -f macos.yml up -d
docker-compose -f ios.yml up -d
